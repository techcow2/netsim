# 🧪 NetSim Beta Build

## Overview

Welcome to the beta version of NetSim! This experimental build introduces several new features and improvements, but also contains some known issues. Please read this document carefully before using the beta build.

## ✨ New Features

### 🔑 In-App API Key Management
- Configure your API keys directly from the user interface
- No need to modify source files manually
- Secure local storage of your credentials

### 🧠 Expanded Model Support
- **Deepseek Integration**: Access to Deepseek's powerful AI models
- **Gemini Support**: Use Google's Gemini models for simulations
- Configure model-specific settings through the new settings panel

### 🚀 Performance Improvements
- **Increased Token Limits**: Generate longer, more complex simulations
- Improved handling of complex rendering tasks
- Better resource management for smoother performance

## ⚠️ Known Issues

### Critical Issues
- **⛔ Back Button Functionality**: The browser back button is currently non-functional. Use the in-app navigation instead.
- **⛔ Saving Mechanism**: The simulation saving feature is broken in this build. Please export any important work manually.

### Minor Issues
- Occasional rendering glitches with complex simulations
- Some CSS inconsistencies when using certain models
- Limited compatibility with older browsers

## 🛠️ Installation

1. Navigate to the `beta` folder in the main repository
2. Follow the standard installation instructions from the main README
3. Note that this build requires the same prerequisites as the main build

## 🔍 Testing Focus

We're particularly interested in feedback on the following areas:

1. The new API key management interface
2. Performance of the newly supported models
3. Comparison of simulation quality between different models
4. Overall stability during extended usage

## 📣 Providing Feedback

Your feedback is crucial for improving NetSim! Please report any issues or suggestions through one of these channels:

- Open an issue on our GitHub repository
- Join our Discord server and post in the #beta-feedback channel
- Send an email to beta-feedback@netsim.example.com

## ⏪ Reverting to Stable

If you encounter critical issues with the beta build, you can revert to the stable version by:

1. Returning to the main directory
2. Following the standard installation instructions in the main README
3. Note that simulations created in the beta build might not be compatible with the stable version
